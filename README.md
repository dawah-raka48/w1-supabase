## الحالة الحالية

- ✅ تم نسخ ملفات الواجهة وملفات CSS/JavaScript والأصول، بما فيها الصور والفيديو، من النسخة الأصلية.
- ✅ أضيفت ملفات تجهيز قاعدة بيانات Supabase وخطوة نسخ ملفات PDF.
- ✅ عطّلنا الاتصال بواجهة Google Apps Script القديمة في هذه النسخة حتى لا تؤثر عمليات التجربة على بيانات الإنتاج.
- ⏳ لم يتم تشغيل SQL في مشروع Supabase من خلال هذه المحادثة.
- ⏳ لم يبدأ نقل PDF فعليًا، ولم تتغير بيانات Google Sheets أو ملفات Google Drive.
- ⏳ لم يتم تحويل تسجيل الدخول وبقية عمليات الواجهة إلى Supabase بعد، لذلك النسخة مرحلة تجهيز وليست جاهزة للاستخدام التشغيلي.

## ملفات Supabase

1. `supabase/migration.sql`: حاوية PDF خاصة وجدول تتبع النقل.
2. `supabase/app-schema.sql`: مخطط مبدئي لمستخدمين وتقارير وإعدادات مع سياسات RLS.
3. `supabase/google-apps-script/W1PdfMigration.gs`: سكربت لنسخ الملفات من Google Drive إلى Supabase Storage دون تعديل المصدر.
4. `supabase/README.md`: خطوات التشغيل والتحقق.

## الأمان وعدم فقد البيانات

- لا تضع مفتاح `service_role` في هذا المستودع أو في أي JavaScript يعمل في المتصفح.
- يحتفظ Google Drive بالملفات الأصلية؛ النقل عبارة عن نسخ فقط.
- يظل جدول Google Sheets كما هو؛ سكربت PDF يقرأه فقط.
- لا تعتمد هذه النسخة قبل تشغيل SQL، ومراجعة أسماء الأعمدة الفعلية، واختبار عينة صغيرة ومطابقة النتائج.
- مشروع Supabase يستخدم حاوية خاصة، ولن يحصل المستخدمون على حق الوصول للملفات إلا بعد إعداد سياسة وصول مرتبطة بصلاحيات الأدوار والأقسام.
- هذه الواجهة الحالية مبنية HTML/CSS/JavaScript ثابتة وليست Next.js؛ لذا لا تحتاج `npm install @supabase/ssr` أو `page.tsx` إلا إذا قررنا لاحقًا تحويلها إلى Next.js.

## التشغيل

افتح `index.html` عبر استضافة ثابتة أو GitHub Pages بعد اكتمال ربط Supabase. في وضع التجهيز الحالي، سيعرض تسجيل الدخول رسالة بأن إعداد Supabase لم يكتمل بدلًا من الاتصال بالنظام القديم.
